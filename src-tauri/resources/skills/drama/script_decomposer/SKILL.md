---
name: script_decomposer
description: 把短剧剧本拆成分集、分镜，以及可复用的角色、场景、道具提示词。
metadata:
  agent: drama
---
输出严格 JSON：episodes、assets。每个 episode 包含 name 和 shots；每个 shot 包含 title、original_text、prompt、references；references 每项有 asset_type、asset_name，角色需要某个非基础形态时额外有 variant_name。assets 中只能使用 character、scene、prop 三种 type，每个素材必须有稳定的、带真实含义的 name、source_evidence 和适合图像生成的独立 prompt；source_evidence 必须是从输入剧本逐字复制的、最多48字的连续原文，且必须包含 name，用于证明该实体确实存在。不能提供这项原文证据就不得输出该素材。character 可带 variants，每项为 name、prompt、episode_numbers。先通读全部剧本，在内部建立素材清单，再输出 assets：剧本中每一位有姓名或稳定称谓、参与动作/对白/剧情推进的人物都必须有一个 character；每个实际发生剧情且可复用的地点/空间都必须有一个 scene；每件被持有、使用、被寻找、被展示或推动剧情的关键物件都必须有一个 prop。角色 name 只能是原文中的名字或稳定称谓，场景 name 只能是原文中的明确地点/空间，道具 name 只能是原文中的具体物件；绝不能将对白、旁白、动作、情绪、镜头术语、时间天气或任意截取的连续字作为素材名称。素材数量由剧本文本决定，不得按“每类 2 个”或任何固定数量凑数，也不得为了少输出而省略人物、场景或道具；仅在某一类型确实完全没有出现时才可输出 0 个。
角色 name 必须是简短真实的人名，例如“林岩”“道玄”“苏晚”；身份、职业、阵营和叙事功能只能放在角色 prompt 中；角色性格不能只写一个形容词，必须补充至少 3 个可观察的行为特征，覆盖待人方式、压力下的情绪反应、思考或决策习惯、对重要人物的态度、说话或行动倾向中的至少三项，禁止使用“山村遗孤·少年剑修”这类代称。
不要生成“主要角色”“主要场景”“关键道具”等泛化素材，也不要生成图片或视频 URL。素材 prompt 必须遵循 asset_prompt_generator 的格式，不能把完整剧本复制到每个角色、场景或道具 prompt。每个角色、场景、道具 prompt 第一行必须写“叙述背景主题：<theme 参数原文>”，并保证角色服饰、场景建筑与陈设、道具形制与工艺符合该背景的时代、地域和技术水平；剧本未明确穿越时禁止混入跨时代元素。只要剧本中同一角色具有两个以上可视觉区分形态（含幼年/少年/成年/老年、变身、伤病、身份伪装和明显换装），必须完整输出基础形态和每个非基础形态 variants；每个分镜的 references 必须引用当时实际形态的 variant_name，绝不可仅引用角色姓名或把不同形态混合到一张图。
请按照剧情时间线均匀拆解剧本：每个分镜只表达一个连续动作或一个明确的信息变化，每个分镜剧本文字不得超过{shot_script_max_chars}字、约 3～8 秒视频。original_text 只能填写当前分镜的短文本片段，禁止把完整剧本复制到每个分镜，禁止多个分镜重复同一段；完整剧本中的事件要按顺序分配到各个分镜。人物首次出场时，必须把剧本中的“【人物首次出场：当前名字｜人物描述：…】”完整保留到该人物首个分镜的 original_text，并同步写入 prompt；若原文漏标，按全剧时间线在该人物首个清晰出场处分镜补写此标记。对应镜头必须增加“【人物姓名标识｜姓名：当前名字｜时长：1～2s｜位置：人物近旁且不遮挡脸部｜效果：快速淡入淡出】”，只出现一次；姓名必须使用当前剧情中的名字或与对应 character 素材一致的当前 name。姓名标识不是对白或字幕，即使项目关闭 subtitles 也必须保留，非首次出场不得重复。分镜要能直接用于后续的视频提示词生成，明确主体、动作、场景、镜头、光线、风格、分辨率和字幕/背景音乐约束。遇到“【第001集：集名】”格式的长剧正文时，必须按既有集号拆成独立 episode，不能重新合并；每集生成2至4条按时间顺序衔接的分镜。每条 prompt 均使用富文本分段结构：“场景：\n@图1（场景）\n\n角色：\n@图2（角色）\n\n道具：\n@图3（道具）\n\n风格：…\n光线：…\n位置：…\n\n【镜头1 | …】…”。引用可先保留为待生成素材，禁止把整集、整部剧或原始用户剧本直接填入 prompt。
